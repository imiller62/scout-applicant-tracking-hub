## Overview

Scout gives hiring and recruiting teams a web application for moving applicants through a structured pipeline. Applicant tracking and hiring progress share one workspace, so teams can see recruitment activity more clearly.

The tool suits organizations that want a focused way to arrange candidates and follow each person's path through the hiring process. Because everything is organized around the pipeline, recruiting work stays in order without needing a separate system for every stage.

---

## Key Capabilities

- Run a structured, well-organized hiring pipeline
- Follow applicants as they move through recruiting workflows
- See candidate progress at every hiring stage
- Handle applicant tracking from within the browser
- Keep recruitment activity in one centralized view
- Coordinate hiring from a single focused workspace
- Check pipeline status through one application

## How to Use

A common Scout session looks like this:

1. Launch the Scout web application.
2. Add applicants to the hiring pipeline or review the ones already there.
3. Sort applicants by the recruiting stage they are currently in.
4. Monitor pipeline progress while coordinating hiring work.
5. Come back to the application as recruitment moves forward.

What you can do depends on the current application build and how its interface is configured.
